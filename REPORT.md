## Challenges & Fixes

- **Starting from nothing with Unity**
  I had never tried to built a game in Unity, so it was incredibly difficult having no knowledge and having to create a game. I solved this problem with lots of Youtube videos and reading online to learn how to build a good game. Breaking the game into smaller pieces, such as building the scene, then adding functions to each object, etc., made the process much more manageable.

- **Debugging gameplay logic (mostly saving the game)**
  Having to build a data persistence manager was incredibly difficult, and was by far one of the most difficult aspects of building the game. Data persistence was essential to save players positions, so having to build the system, then add encryption was incredibly difficult, filled with many errors. I solved this through Youtube and again, more researching online.
